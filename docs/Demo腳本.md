## 評審可能會問

- **勝率怎麼算？** 不給百分比。依法規檢核分高／中／低，附公開統計作參考基準（臺中市申訴免罰約兩成）。
- **法規修正怎麼辦？** 知識庫獨立於程式，有版本日期；修改 JSON 即可，測試會確認規則仍正確。
- **會不會變成教人逃罰單？** 系統只找法律上真的站得住的理由；沒有理由時明確建議繳納。
- **個資？** 網頁版不保存上傳內容，只產生文件供下載。
- **是否違反律師法？** 定位是文書與程序輔助工具，使用者自行判斷與遞交，並提供法扶等真人資源。
